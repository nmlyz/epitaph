epitaph writes one line to a text file: the funniest one-line epitaph, a single line of famous last words carved in stone. The line was picked from 36 candidates by pairwise judging against the brief — the speaker finally wins the last word, only for that word to be "oops": a win that is also a loss, in one short line.

## Run it

```sh
python3 main.py
```

It writes the line to `/output/entry.txt` (or `$MAKEFUN_OUTPUT_DIR/entry.txt`). No network access needed; the same text, byte for byte, on every run. The line is 43 characters, a single line, and ends on its strongest beat. The program holds the line as one constant and checks it against the entry gate (length, single line, no leading or trailing space, exact judged length) before writing it, then reads the file back to confirm the bytes match.
